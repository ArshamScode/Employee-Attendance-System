# وثائق برنامج التثبيت

يحتوي هذا المجلد على سكربت Inno Setup والوثائق المساعدة اللازمة لإنشاء ملف تثبيت لنظام Windows لبرنامج **Employee Attendance System**.

## محتويات المجلد

* `InstallerScript.iss` — سكربت إعداد Inno Setup.
* `License.txt` — شروط الترخيص التي تظهر أثناء التثبيت.
* `BeforeInstall.txt` — المعلومات التي تظهر قبل التثبيت.
* `AfterInstall.txt` — التعليمات التي تظهر بعد التثبيت.

## المتطلبات

* نظام التشغيل Windows
* إصدار من Inno Setup متوافق مع السكربت
* نسخة جاهزة للإصدار من البرنامج باسم `AttendanceSystem.exe`
* جميع مكتبات وقت التشغيل وإضافات Qt واعتماديات OpenCV وملفات النماذج المطلوبة

## إنشاء ملف التثبيت

1. قم ببناء البرنامج في Visual Studio باستخدام إعداد Release المناسب.
2. جهّز الملف التنفيذي للبرنامج وجميع اعتماديات وقت التشغيل المطلوبة.
3. افتح الملف `InstallerScript.iss` باستخدام Inno Setup.
4. تحقق من أن جميع مسارات الملفات في السكربت تشير إلى الملفات الصحيحة على جهازك.
5. تأكد من توفر أيقونة البرنامج وملف الترخيص وملفات معلومات التثبيت وإضافات Qt ومكتبة OpenCV وملفات النماذج في المسارات المحددة.
6. قم بترجمة السكربت وإنشاء ملف التثبيت باستخدام Inno Setup.
7. اختبر ملف التثبيت الناتج في بيئة Windows منفصلة قبل توزيعه.

## ملاحظات مهمة

* قد تحتاج إلى تعديل مسارات الملفات عند استخدام السكربت على جهاز كمبيوتر آخر.
* لا تضع المعلومات الشخصية للموظفين أو صور الوجوه الحقيقية أو سجلات الحضور والانصراف الخاصة في مستودع عام أو داخل ملف التثبيت.
* يجب أن يتضمن ملف التثبيت جميع الاعتماديات اللازمة لتشغيل البرنامج.
* راجع التراخيص المعمول بها لكل من Inno Setup وQt وOpenCV وجميع الملفات التابعة لجهات خارجية التي ستعيد توزيعها مع البرنامج قبل نشر ملف التثبيت.
* يُفضّل نشر ملف التثبيت النهائي والملفات المؤقتة الناتجة عن عملية البناء عبر قسم GitHub Releases، بدلاً من إضافتها مباشرةً إلى هذا المجلد.

## إخلاء المسؤولية

تشرح هذه الوثائق عملية تجهيز حزمة التثبيت المقصودة. ويعتمد نجاح إنشاء ملف التثبيت وتشغيله على إعدادات المشروع الفعلية والاعتماديات المتوفرة وصحة مسارات الملفات.
