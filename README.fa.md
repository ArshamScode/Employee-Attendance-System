## معرفی

سامانه حضور و غیاب کارکنان یک برنامه دسکتاپ ویندوز برای مدیریت اطلاعات کارکنان، بررسی رویدادهای ورود و خروج، تنظیم قواعد ساعات کاری و خروجی گرفتن از داده‌های حضور و غیاب است. برنامه شامل گردش‌کار دوربین با استفاده از تشخیص چهره و مقایسه تصاویر در OpenCV است. این پروژه یک نمونه‌کار نرم‌افزاری است و محصولی تأییدشده برای منابع انسانی، ثبت رسمی ساعات کاری، امنیت یا شناسایی زیستی محسوب نمی‌شود.

## قابلیت‌ها

- **صفحه Attendance:** نمایش وضعیت حضور و گردش‌کار ثبت حضور با دوربین.
- **مدیریت کارکنان:** ایجاد، مشاهده، ویرایش و حذف پرونده کارکنان، همراه با عکس پروفایل.
- **سوابق حضور و غیاب:** مشاهده و جست‌وجوی سوابق و خروجی گرفتن از داده‌های جدول به CSV.
- **تنظیمات کاری:** پیکربندی قواعد ساعات کاری و حداقل آستانه اضافه‌کاری.
- **پایگاه داده محلی:** ذخیره‌سازی SQLite از طریق Qt SQL.
- **پردازش چهره:** تشخیص چهره با Haar Cascade و مقایسه/آموزش مبتنی بر تصویر. دقت تشخیص به‌طور مستقل ارزیابی نشده است.
- **تعریف نصب‌کننده ویندوز:** اسکریپت Inno Setup موجود است؛ فایل‌های اجرایی و وابستگی‌های بسته نصب جدا از سورس نگهداری می‌شوند.

## فناوری‌ها

- **زبان:** C++
- **رابط دسکتاپ:** Qt Widgets؛ پیکربندی پروژه برای Qt 5.15.2، ‏MSVC 2019 و معماری ۶۴ بیتی است.
- **بینایی ماشین:** OpenCV 4.5.5
- **پایگاه داده:** SQLite از طریق Qt SQL
- **محیط ساخت:** Visual Studio 2019، ابزار `v142` و یکپارچه‌سازی Qt/MSBuild
- **سیستم هدف:** Windows x64

فایل پروژه Visual Studio شامل مسیرهایی وابسته به محیط توسعه است که ممکن است در رایانه‌ای دیگر نیاز به اصلاح داشته باشند. ساخت موفق روی یک سیستم پاک در جریان آماده‌سازی این مخزن تأیید نشده است.

## اطلاعات ورود آزمایشی

اعتبارنامه‌های زیر به‌صورت ثابت در سورس برنامه قرار دارند و فقط برای ورود به بخش‌های نسخه نمایشی درج شده‌اند. این روش احراز هویت امن نیست. از آنجا که مخزن عمومی است، همه می‌توانند این مقادیر را مشاهده کنند. از آن‌ها برای محافظت از اطلاعات واقعی کارکنان یا داده‌های زیستی استفاده نکنید.

## ساخت از سورس

1. Visual Studio 2019 را همراه با Desktop development with C++ و Windows SDK نصب کنید.
2. پیکربندی Qt مورد انتظار پروژه، یعنی `5.15.2_msvc2019_64`، و یکپارچه‌سازی آن با Visual Studio را نصب کنید.
3. نسخه x64 از OpenCV 4.5.5 را نصب کنید و مسیرهای include و library را در `src/AttendanceSystem/AttendanceSystem.vcxproj` با محیط محلی هماهنگ کنید.
4. فایل `src/AttendanceSystem/AttendanceSystem.vcxproj` را در Visual Studio باز کنید، پیکربندی **Release | x64** را انتخاب کنید و پروژه را بسازید.
5. افزونه‌های لازم Qt برای platform، SQL و قالب‌های تصویر، DLL مربوط به OpenCV و مدل Haar Cascade را در دسترس برنامه قرار دهید.
6. پیش از توزیع، خروجی را روی یک سیستم پاک Windows x64 آزمایش کنید.

ساختار اصلی سورس Visual Studio حفظ شده است. فایل‌های خروجی ساخت، تنظیمات شخصی رایانه و داده‌های اجرایی کارکنان در مخزن قرار نگرفته‌اند.

## نصب‌کننده

تعریف نصب‌کننده Inno Setup در [`installer/InstallerScript.iss`](installer/InstallerScript.iss) قرار دارد. مسیر پیش‌فرض نصب، پوشه‌ای زیر Desktop کاربر فعلی است و میان‌بر دسکتاپ به‌صورت اختیاری و غیرفعال در حالت پیش‌فرض ارائه می‌شود. فایل‌های اجرایی و وابستگی‌های بسته نصب در این مخزن سورس قرار ندارند و اسکریپت در این انتشار کامپایل یا آزمایش نشده است. سیاست‌های ویندوز و OneDrive ممکن است بر دسترسی نوشتن تأثیر بگذارند.

اسکریپت پوشه‌های `data/` و `data/faces/` را در مسیر نصب ایجاد می‌کند تا با مسیر نسبی پایگاه داده برنامه، یعنی `data/attendance.db`، هماهنگ باشد. بسته نهایی باید از نظر نوشتن پایگاه داده و تصاویر، بارگذاری افزونه‌های Qt، دسترسی دوربین، حذف نصب و رفتار میان‌بر آزمایش شود.

- این پروژه نمونه‌کار است و محصول تأییدشده برای منابع انسانی، ثبت رسمی ساعات کاری، امنیت یا شناسایی زیستی نیست.
- تطبیق چهره ممکن است نتیجه اشتباه بدهد یا چهره را تشخیص ندهد. تصمیم‌های مهم به بررسی انسانی و جایگزین مناسب غیرزیستی نیاز دارند.
- فقط از داده ساختگی یا داده‌ای که مجوز روشن برای استفاده از آن دارید استفاده کنید و قوانین مربوط به حریم خصوصی، اشتغال و داده‌های زیستی را رعایت کنید.
- این مخزن اثبات نمی‌کند که پایگاه داده محلی رمزگذاری شده یا دارای کنترل دسترسی مناسب برای محیط عملیاتی است.
- Qt، OpenCV، SQLite، افزونه‌های Qt و سایر وابستگی‌ها شرایط مجوز و اعلان‌های جداگانه دارند؛ به [`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md) مراجعه کنید.
